# Шрифты Fionix

По умолчанию интерфейс использует системный **Segoe UI** (Windows 10/11).
Сюда можно положить собственные `.ttf`-файлы — они регистрируются при старте
через `QFontDatabase.addApplicationFont()`.

Чтобы новая гарнитура применилась ко всему интерфейсу, измените `FONT_FAMILY`
(и при необходимости размеры/начертания) в `src/core/theme.py` и в кастомных
художниках `src/ui/widgets.py`.

Проверяйте лицензию шрифта перед распространением сборки: не все бесплатные
шрифты разрешают встраивание в приложение.
